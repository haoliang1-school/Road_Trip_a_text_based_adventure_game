# **Road Trip**

Road Trip is a python based text based interactive adventure game, where you make the decision.

## **Installation**

Python is required to run this game, to download python, navigate to the download page on their website and donwload [3.13](https://www.python.org/downloads/)

## **How to run the game**

```python
python game.py
```
